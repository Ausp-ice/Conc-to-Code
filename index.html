    How to prepare your draft

    Getting the HTML out of Google Docs
    1. Use Google Docs' heading styles (Format → Paragraph styles) for section titles. Big bold text that isn't a real heading won't be recognised.
    2. Resolve comments and accept or reject suggestions first, or they can end up in the code.
    3. Select all (Ctrl+A), copy, and paste into the editor at text-html.com. Copy the HTML it produces and paste it in the box above.
    4. Or: in Google Docs, choose File → Download → Web page (.html, zipped). Unzip it and upload the .html file.
    Basics (top of the doc)

    Everything before the first Heading 1 is the top of the profile. Write each Basics field as a bold label with a colon, then the value. Put them on separate lines; Shift+Enter line breaks are fine.

    Name: Onaara
    Pronunciation: [oh-NAR-uh]
    Idea: Theophagy
    Pronouns: she/they/it
    • Fields with a spot in the layout: Name, Pronunciation, Idea, Prominence, Origin, Gender, Pronouns, Species, Masterlist, Previous Species (or Previous Form), Era of Birth, Themes, Significant Dates (or Age/Dates), CW.
    • Settings: Accent: a hex colour for the profile's theme (e.g. #bda891), Toyhouse: the character's toyhou.se link (used for the gallery links), Quote: an in-character quote, Owner: your toyhou.se username.
    • Any other bold label is listed in the notes so you can place it yourself.
    • Ordinary paragraphs up here become the Intro. An optional first line like "Onaara, Edeia of Theophagy" is skipped.
    Sections (Heading 1)

    Each Heading 1 starts a section. These names are recognised:

    • Personality (or About): if it opens with an italic quote in quotation marks, that becomes the in-character quote.
    • Idea Interpretation
    • Abilities: a Heading 2 Idea Magic, then one Heading 3 per ability. A General Edeia Abilities heading is skipped, since the layout already includes that paragraph.
    • History (or Story): a bullet list at the very start becomes the timeline. After that, each Heading 2 is an era that goes under "Read more". A Heading 2 called Full Story holds a long version with no eras.
    • Abstraction
    • Relations and Relations with Others, plus Fusions: see below.
    • Design (or Appearance): bold label lines like Height:, Voice: and References:, then bullets for design notes.
    • Playlist: one linked song per line or bullet. YouTube links get a working play button.
    • Notes (or Trivia): bullet points.
    • Any other Heading 1 (e.g. Followers) gets its own box after History.
    Relations and fusions

    Use one Heading 2 per character. If the next line is entirely in italics, it becomes the relation type.

    Relations (Heading 1)
    Sylnae (Heading 2)
    Mentor
    Onaara met Sylnae when…
    • Characters in the converter's character list are filled in automatically with their link, image and owner. Spell the name the same way.
    • For anyone else, make the Heading 2 a link to their toyhou.se page, and add the image afterwards.
    • Enter your username above (or add an Owner: field) so your own characters don't get an "Owner:" line.
    After converting
    • Read the list of notes. Anything marked TBD in the code needs filling in.
    • Images in the doc aren't carried over. Add image links for the header, focal art, Abstraction, alt forms, playlist covers and relation pictures.
    • Ability tags start as TBD tag.
    • The "design by / art by" credit links point to Auspice by default. Change them to the right artists.
    • Paste the code into your Toyhouse profile's HTML editor. Search the code for TBD to find every gap.
